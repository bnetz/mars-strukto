Mars-Strukto einbinden

Mars-Strukto ist der Struktogramm-Editor aus dem Lernspiel Escape from Mars. Schülerinnen und Schüler bauen damit Struktogramme nach der Operatorenliste für Struktogramme (Abitur Baden-Württemberg, Version 2.2), führen sie aus – mit Konsole, Ein- und Ausgabe, Variablenanzeige und Schritt-für-Schritt-Ablauf – und speichern sie als Datei oder Bild. Alles läuft im Browser, ohne Anmeldung, ohne Cookies, ohne Bibliotheken.

Diese Seite ist für Lehrkräfte und alle, die den Editor in eine eigene Seite (Schulhomepage, Moodle-Textseite, eigene Website) einbauen möchten. Es gibt zwei Wege.

Weg 1: In zwei Zeilen von escape-from-mars.de einbinden

Diese zwei Zeilen an die Stelle der eigenen Seite setzen, an der der Editor erscheinen soll:

<script src="https://escape-from-mars.de/mars-strukto/1/mars-strukto.js"></script>
<div class="mars-strukto"></div>

Das ist alles. Die erste Zeile lädt den Editor (Skripte, Aussehen und Schriften) von escape-from-mars.de, die zweite legt fest, wo er erscheint. Verbesserungen an Version 1 kommen bei diesem Weg automatisch an.

Datenschutz bei Weg 1: Der Browser Ihrer Besucher lädt dabei Dateien von escape-from-mars.de; dabei werden – wie bei jedem Abruf aus dem Internet – IP-Adresse, Browserangaben und die Adresse Ihrer Seite übermittelt. Erwähnen Sie das in Ihrer Datenschutzerklärung (Textvorschlag unten). Wer das vermeiden will, nimmt Weg 2.

Einstellungen

Angabe am divWirkung
style="height: 600px"Höhe des Editors. Ohne Angabe: drei Viertel der Fensterhöhe, mindestens 520 Pixel.
data-name="Notenschnitt"Programmname für ein neues Struktogramm.
data-speichern="aufgabe-3"Unter diesem Namen merkt sich der Browser das Struktogramm. Nützlich, wenn mehrere Seiten den Editor enthalten und jede ihr eigenes Struktogramm behalten soll. data-speichern="nein" merkt nichts.

Beispiel mit allen Angaben:

<script src="https://escape-from-mars.de/mars-strukto/1/mars-strukto.js"></script>
<div class="mars-strukto" data-name="Notenschnitt" data-speichern="aufgabe-3" style="height: 600px"></div>

Mehrere Editoren auf einer Seite sind möglich: einfach mehrere div mit der Klasse mars-strukto einsetzen (die Skriptzeile nur einmal). Sie laufen unabhängig voneinander.

Hinweise

  • In Bludit und anderen Systemen, die Markdown verarbeiten: keine Leerzeile zwischen den beiden Zeilen.
  • Der Editor braucht etwa 900 Pixel Breite für die Ansicht nebeneinander; schmaler stehen Struktogramm und Konsole untereinander.
  • Die einbindende Seite sollte keine eigenen globalen JavaScript-Namen Programm, Struktogramm, Interp, SgEditor, SgArbeitsplatz, SgPaket, SgSchrift, SgEinbau oder MarsStrukto verwenden (außer natürlich MarsStrukto über die Schnittstelle).

Eigene Befehle anmelden (Schnittstelle)

Eine Seite kann dem Editor eigene Befehle beibringen – etwa die Befehle einer Roboter-Welt, eines Spiels oder einer Simulation, so wie Peetie in Escape from Mars. Der Editor schlägt sie dann vor, prüft sie und ruft beim Ausführen eine JavaScript-Funktion der Seite auf:

<script src="https://escape-from-mars.de/mars-strukto/1/mars-strukto.js"></script>
<div class="mars-strukto"></div>
<script>
  MarsStrukto.befehle([
    { name: 'geheVor', text: 'Der Roboter geht ein Feld vor.',
      ausfuehren: async function () { /* Roboter bewegen */ } },
    { name: 'wandVoraus', rueckgabe: 'Wahrheitswert', text: 'wahr, wenn vorne eine Wand ist.',
      ausfuehren: function () { return false; } }
  ]);
</script>

Die vollständige Beschreibung – Parameter und Datentypen, Rückgaben, Fehlermeldungen, Animationen, Start und Ende eines Laufs – steht in API.md; sie ist so geschrieben, dass auch ein KI-Assistent damit arbeiten kann. Ein lauffähiges Beispiel mit einer kleinen Roboter-Welt: Beispiel: eigene Befehle.

Weg 2: Kopie auf dem eigenen Server (oder offline)

mars-strukto.zip herunterladen und entpacken. Der Ordner mars-strukto enthält alles, was der Editor braucht.

  • Auf dem eigenen Server: den Ordner hochladen und die zwei Zeilen mit dem eigenen Pfad einsetzen, z. B. <script src="/mars-strukto/mars-strukto.js"></script>. Dann entsteht keine Verbindung zu escape-from-mars.de. Neue Versionen kommen bei diesem Weg nicht von selbst an.
  • Offline (Schulrechner, USB-Stick): index.html im Ordner doppelklicken. Läuft ohne Internet.

Dateien und Speichern

Struktogramme werden als .struktogramm.json gespeichert, Bilder als PNG oder SVG. Die Dateien sind dieselben wie in Escape from Mars – Struktogramme lassen sich zwischen beiden hin- und hertauschen. Zusätzlich merkt sich der Browser das aktuelle Struktogramm (Local Storage), sodass nach dem Neuladen nichts verloren ist. In Schulnetzen, die Browserdaten beim Abmelden löschen, hilft nur „Speichern“.

Struktogramm-Editor Mars-Strukto

Auf dieser Seite ist der Struktogramm-Editor Mars-Strukto eingebunden. Seine Dateien (Skripte und Stile, die Schriften sind darin enthalten) lädt Ihr Browser vom Server escape-from-mars.de. Dabei werden – wie bei jedem Abruf einer Datei aus dem Internet – Ihre IP-Adresse, Angaben zu Ihrem Browser und die Adresse dieser Seite an den Betreiber von escape-from-mars.de übermittelt. Dieser verwendet die Angaben nach eigener Aussage nur in seinen Server-Logfiles, die anonymisiert und automatisch gelöscht werden; er setzt keine Cookies und zählt die Aufrufe nicht (Datenschutzerklärung: https://informatik-bg.de/datenschutz). Rechtsgrundlage ist unser berechtigtes Interesse, Ihnen den Editor für den Unterricht bereitzustellen (Art. 6 Abs. 1 lit. f DSGVO).

Was Sie im Editor bauen, ausführen oder eingeben, bleibt in Ihrem Browser und wird weder an uns noch an escape-from-mars.de übertragen. Damit Ihre Arbeit nicht verloren geht, speichert der Editor das aktuelle Struktogramm und die Stellung des Tempo-Reglers im Local Storage Ihres Browsers (unter der Adresse dieser Seite). Das ist für die von Ihnen gewünschte Funktion erforderlich (§ 25 Abs. 2 Nr. 2 TDDDG). Sie können die Daten jederzeit über die Einstellungen Ihres Browsers löschen („Websitedaten löschen“).

Der Editor kommt ohne Gewähr und ohne Unterstützung – es gibt keinen Anspruch auf Hilfe, Fehlerbehebung oder Weiterentwicklung.

Die eingebetteten Schriften „Mars Sans“ und „Mars Code“ sind umbenannte Teilmengen von Source Sans Pro und Source Code Pro (Adobe), die Seiten von Mars-Strukto verwenden außerdem Barlow. Alle drei stehen unter der SIL Open Font License 1.1 (Dateien fonts/OFL*.txt) und kommen vom selben Server wie der Editor. Der Schriftzug „Mars-Strukto“ ist eine Grafik mit der Schrift Nasalization (Typodermic Fonts).
